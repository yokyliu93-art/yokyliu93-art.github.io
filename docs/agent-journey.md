# Agent、岛屿与私人来信

## 创建路径

主页 → 注册/登录 → `/?view=connect` → Agent 的真实 hello → onboarding → 后台编程任务 → studio 展示代码生成的 3D 世界 → `/?view=reflection` 岛内信。

岛屿钥匙是本站的授权凭证，不是模型供应商的 API Key。用户在自己的 Codex、Claude Code 或其他 Agent 中使用自己的模型配置。生成连接文件不代表连接成功；Agent 必须 POST `/api/islands/:id/hello`。撤销、过期的钥匙不再解锁新创作。连接页显示最后一次问候和是否在最近 90 秒内活动。

客户端不再调用宿主 Codex。连接文件介绍完整 SDK，轮询 `/coding-task`，通过 PUT `/program` 返回真实 JavaScript 和可选 `scenePatch`。权限包括自己的生态、内部空间、角色；可按需开放个人记忆读写。账号、社交同意与他人的岛不属于编程权限。JS 在隔离 worker 中执行，网格数量、范围、执行时间和源代码大小有限制。不能把“开放创作”变成宿主文件系统或其他用户的权限。

Onboarding 的自由描述与所有选择进入同一编程任务。保存偏好、写入记忆、创建任务在一个 SQLite 事务内完成，失败全部回滚。重新打开 studio 会从服务端恢复未完成任务；不会依赖同一浏览器的会话缓存。草稿缓存使用账号 ID 分隔。

## 分析接口和数据

后台 `island_letters` 保存每次变更的账号、岛屿版本、完整设计/代码、用户选择、原话、修正、变更记录和分析结果。首次成功创作准备个人来信，之后生成短的变化来信。旧的通用兜底画像不会显示在新邮箱里，也不会伪装成模型结果。缺少文字 API Key 时状态为 `waiting_provider`。

配置参见 `docs/island-services.env.example`，复制到根目录 `.env`，填写后重启服务。后端读取这些变量；不要加 `VITE_` 前缀。支持独立的文字分析与生图供应商。DeepSeek 文字模型用于分析，图片生成需要另一个实际支持 `/images/generations`、返回 `b64_json` 的服务。无需微调即可更换分析模型或编辑 `server/island-mail.js` 的 `LETTER_PROMPT`。

分析不是标准化测评。MBTI 必须有用户主动表达作为证据，每轴至少两个有效引用，否则完整类型留空；不展示虚构概率，不据此自动决定关系。代码和 Agent 自行加入的默认细节作为设计上下文，不应被当成用户心理事实。用户修正进入自己的可导出记忆。模型推测单独存为来信，不会当成用户原话重新写入记忆。

插画按这封信的主题分别请求，二进制保存到 `island_letter_images`。读取必须带岛主自己的凭证，不使用包含个人信息的公开静态图片地址。没有生图配置时文字依然可读，显示插画待配置；不拿同一张历史图片冒充个性化生成。客户端可重试、修正、删除信件。

后台每 15 秒处理一个任务，数据库租约防止重复领取，处理中断后 4 分钟可恢复。上游失败显示失败状态，用户可重试。每天上海时间零点之后整理前一天的变化，最多补过去 7 天；同一账号同一天只建一封。启用新邮箱前的历史事件不会自动补发。需要 Node 服务持续运行，静态 GitHub Pages 单独不能承担账号、数据库、后台队列。

## 3D 与时间

星球使用光滑球体、沿球面的陆地、云和环带；海洋有水体厚度、细分波面、两处浅滩和可点击暂停的帆船。模板仅为起点，自定义 Agent 代码不会被模板升级覆盖。内置动物不会因选择星球/海洋而被过滤掉。

完整昼夜周期为现实 10 分钟：长白天 8/2 分钟，长夜 2.2/7.8 分钟，均衡 5/5 分钟。时间原点随选择保存到岛屿，切换页面或刷新不会重置。日光、太阳位置、夜空、星星和补光连续联动。长夜的实际亮度低于白天，保留看得清角色的月光。

## 验证

`npm run test:server` 覆盖 hello/撤销、跨账号隔离、事务回滚、个性化快照、缺少模型、迟到结果与删除、每日幂等、昼夜比例、全部世界模板资源规则。`npm run build` 验证前端构建。真实文字和生图端到端验证需要配置有效供应商密钥；测试注入结果不算真实 AI 成功。
