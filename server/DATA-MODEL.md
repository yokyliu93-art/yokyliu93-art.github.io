# 岛屿、授权与关系数据模型

## 存储

SQLite 文件位于 `data/islands.sqlite`（已忽略版本控制）。开启外键与 WAL；场景修改、合岛确认和资产归还均使用事务。Node.js 24+。本地运行 `npm run dev`，API 与网页同源。`npm run preview` 也挂载 API；只把 dist 上传静态站点不能提供数据库功能。

- users / islands：一人一座个人岛，所有权固定。scene JSON 是带规则版本的受限场景文档，内含生态类型、季节、环境、物件与可为空的房间，revision 用于防止并发覆盖。
- credentials：人类身份与 Agent 凭证分开；只存随机 token 的 SHA-256，不存明文；有区域权限、到期时间、撤销时间。
- creations：描述、任务状态、原版本、修改前快照、摘要与错误；每岛同时一个任务，每人每天最多 10 次，支持撤回最新成功结果。
- audit：每次成功写入及关系操作记录身份、动作、对象与时间，不记录明文 token。
- encounter_rounds / encounters：UTC 日轮次、无序岛屿对、概率、抽签值、结果及解释。每日同一对仅一条结果。
- bonds：pending → active / declined；pending、active 可由任一方解除为 separated。一次仅允许一个待处理或活跃合岛关系。再次合岛产生新记录。
- shared_spaces / shared_objects：合岛后的独立共同空间；物件记录创作者所有权，不能覆盖另一方的物件。
- returned_objects：分开后的个人收纳箱；原岛已满也不会丢失共同空间创作。可从工作室放回当前房间；校验失败时保留收纳物件，不会丢失。
- blocks：双方任一方屏蔽后停止发现、拜访和新相遇，并结束待处理或活跃关系。

## 相遇规则（产品假设 v1，可调整）

先检查双方自愿开放发现、未屏蔽。按自然物件、生活物件、阅读与音乐物件、天气、昼夜、声音生成六维向量，余弦相似度为 S。每个 UTC 日轮次相遇概率：

`P = 0.03 + 0.27 × S³`，上限 30%。相遇后的七天冷却期概率为 0。

使用数据库中保留的随机服务端种子、日期、规范化岛屿对生成抽签值；用户重复触发无法重抽。概率是游戏规则，不是现实关系预测。距离 `20 + 80 × (1 − S)` 米是布局建议值，目前在关系数据中返回，没有改变演示群岛的全局坐标。

本地版由 UI 手动触发当日整个世界轮次，上限 200 座开放岛（O(n²)）。生产版需由服务端调度、空间近邻候选检索和分页替代；不要把该本地规模实现直接当成线上全量匹配服务。

## 相遇后与合岛

发生相遇时，两边的相遇列表出现同一条记录，并可发起合岛邀请；不自动建立情感关系、开放编辑权限或发送站外消息。邀请发起人不能替对方确认。确认只创建共同空间，个人岛 ID、场景及所有者不变。

任一方都能结束关系，不必获得另一方同意。共同空间关闭并归档，物件按 creator/owner 进入各自收纳箱，整个操作是原子的，个人岛完全不变。历史关系保留用于审计。系统不推断现实中是否分手，由用户主动操作。

## 当前范围

- 维护入口 `/?view=tools` 的身份、家具、授权、概率轮次、合岛和分开调用真实本地 API 并持久化。
- 虚空大陆首页仍是美术与连接流程演示，没有把所有本地账户自动替换进预览群岛；之前的庭院小游戏仍使用原 localStorage 存档。
- 还没有正式身份提供商、账号找回、线上部署、多设备登录、WebSocket 同步、任意 Agent 代码沙箱；本机 Codex 生态生成仅为显式开启的本地适配器。
- 本地身份 token 保存在本机浏览器，创建账号不验证现实身份。正式发布前需要完善认证、限流与运维，不能把当前账号创建流程当成生产注册系统。

## 引导与偏好记忆

`user_preferences` 保存动物、昼夜、住所、风景四个用户确认的选项，来源固定为 user_onboarding。不是心理量表得分或诊断。GET/POST/DELETE `/api/preferences` 仅岛主本人可用；保存场景使用 revision 防并发覆盖，取消记忆会删除偏好记录，单独删除记忆不改岛屿。后续本地 Codex 创作由后端注入这些偏好，新请求优先。公开岛屿接口不返回记忆记录（开放的场景本身仍可被看到）。

初始引导采用受限场景规则即时预览并保存，不假装这是模型生成。自由文字补充进入个人岛输入框，用户点击创作后再由 Agent 执行。昼夜 day/night/balanced 控制 4 分钟艺术时间周期，白天比例分别 75%/25%/50%；非真实天气和现实日照。
